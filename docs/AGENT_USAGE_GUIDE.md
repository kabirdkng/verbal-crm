# Agent Usage Guide

## Recommended Primary Agent
Use Delivery Orchestrator for feature delivery and cross-role coordination.

## Role Agent Selection
- Product framing: Product Owner
- Architecture decisions: Technical Architect
- Sprint planning: Scrum Master
- Implementation planning: Tech Lead
- End-to-end build: Full Stack Engineer
- WhatsApp, queues, eventing, and AI pipelines: Backend Integrations and AI Engineer
- Dashboard and workflow UI: Frontend UX Engineer
- Prompting and AI behavior: AI Engineer
- CI/CD and operations: DevOps Engineer
- Automated quality strategy: QA Automation Engineer
- UAT planning and sign-off: Manual UAT Coordinator
- UX flow and behavior: Product Designer or UX Designer

## Suggested Invocation Pattern
1. Start with Delivery Orchestrator and describe feature scope.
2. Let orchestrator delegate to required role agents.
3. Review consolidated plan.
4. Execute role-specific implementation tasks.
5. Re-run orchestrator for final readiness assessment.
