# Role Handoff Matrix

## Product and Design
- Product Owner -> Technical Architect: scoped requirements and acceptance criteria
- Product Designer -> Frontend UX Engineer: flow and state requirements
- UX Designer -> Frontend UX Engineer: usability and accessibility improvements

## Architecture and Delivery
- Technical Architect -> Tech Lead: approved design and constraints
- Tech Lead -> Engineers: implementation milestones and quality bars
- Scrum Master -> Team: sprint plan, blockers, and dependencies

## Engineering
- Full Stack Engineer -> QA Automation Engineer: feature behavior and test focus areas
- Backend Integrations and AI Engineer -> QA Automation Engineer: integration edge cases and idempotency points
- Frontend UX Engineer -> Manual UAT Coordinator: user journeys and expected states
- AI Engineer -> QA Automation Engineer: AI quality criteria and failure modes

## Quality and Release
- QA Automation Engineer -> Manual UAT Coordinator: automated evidence and uncovered risk
- Manual UAT Coordinator -> DevOps Engineer: release sign-off status and blockers
- DevOps Engineer -> Product Owner and Tech Lead: deployment status and post-release health

## Minimum Handoff Payload
- What changed
- Why it changed
- Known constraints and risks
- Validation evidence
- Owner for next step
